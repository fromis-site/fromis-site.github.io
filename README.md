# Fromis_9 Tweet Finder - fromis-site.github.io

## 소개
- 프로미스나인 공식 X 트윗 중 멤버들 사진을 포함하는 트윗들을 년-월 카테고리에 따라 분류했습니다.
- 멤버들 나오는 사진 중 앨범 티저, 유튜브 썸네일 등은 제외하고 정리했습니다.(일부 증발해버린 네이버포스트 썸네일 등은 게시함)
- 일본 공트의 경우 원본 게시물은 해결 불가한 문제로 인해 불러오지 못해 한국 공트에서 인용된것만을 게시합니다.(사진이 로드되지 않은 트윗들)
- 일부 페이스북 링크가 있는 트윗의 경우엔 링크타고 들어가시면 사진이 더 있을수도? 있습니다.(21년 생일글 등)
- 기타 다른 사진들은 위버스, 프롬, 페이스북, 공캎 등을 찾아보시는걸 권장합니다.
- 완성 이후 1~6개월 단위로 업데이트 예정입니다.

## 경고
- 개인이 만든 비공식 아카이브임
- 부정확하거나 누락된 자료 있을수 있음
- 대략적으로 트윗 1개당 1-1.5MB의 데이터를 소모합니다. 고로 셀룰러 환경에서의 접속은 권장하지 않습니다.
